# @tulipes/mcp

An [MCP](https://modelcontextprotocol.io) server over a [Tulipes](https://www.npmjs.com/package/@tulipes/core)
app's agent tools: the actions its modules declare in `agent/*.agent.ts`,
each with a description, an input schema and a permission. The app serves
that manifest at its agent door; this package puts it on stdio for Claude
Code, Claude Desktop or any MCP client.

Requires Node 24.x and an app on `@tulipes/core` 0.14 or later (0.2.x for core 0.13) with its
`agent` module mounted (`tulipes init` scaffolds one).

> [!WARNING]
> **Experimental.** This package and the core agent surface it serves are
> outside the 0.13 compatibility promise. Flags, tool naming and the manifest
> may change in any release without a deprecation period.

## In the app's own process: `serveMcp`

Since 0.13 an app generated by `tulipes init` carries `mcp.ts` and a `mcp`
script. It boots the app in script mode and serves its actions in process —
`tools/list` is `ctx.agent.manifest(actor)`, `tools/call` is
`ctx.agent.invoke()` — to the caller `config/mcp.config.ts` identifies:

```ts
// mcp.ts
import { serveMcp } from "@tulipes/mcp";
await serveMcp({ rootDir: import.meta.dirname });

// config/mcp.config.ts
import { defineMcp } from "@tulipes/mcp";
import { identifyCredential } from "../modules/auth/lib/index.ts";
export default defineMcp({ transport: "stdio", identify: (ctx, credential) => identifyCredential(ctx, credential) });
```

```sh
claude mcp add my-app -e TULIPES_MCP_TOKEN="$TOKEN" -- pnpm --silent mcp   # the token in the environment; ps shows argv
```

- `transport: { http: { port, host?, path?, maxBodyBytes? } }` serves MCP's
  Streamable HTTP (stateless) on its own port, default `127.0.0.1` and
  `/mcp`; each request is identified by its `Authorization: Bearer`. Without
  an `identify` it refuses to listen when `APP_ENV` is production or
  staging. On a loopback bind it answers only requests addressed to its own
  address (403 otherwise, against DNS rebinding); behind an ingress the
  ingress checks the host name. A body over `maxBodyBytes` (1 MiB) is
  refused with 413 before `identify` runs.
- No `identify`, or `null` from it, is a guest. `identify` runs on every
  list and call, so a revocation applies to a running session.
- `developmentIdentity("MCP_ROLE")` takes the role from an environment
  variable — for an app without auth — and is refused when `APP_ENV` is
  production or staging.
- A credential's `scopes` narrow the list and the calls as they do over HTTP.
- Every call writes one JSON audit line to stderr (tool, actor, role,
  outcome, duration; never the input). stdout is the protocol; the app's own
  logs are moved to stderr.

## Over the HTTP door: `tulipes-mcp`

```sh
pnpm add -D @tulipes/mcp
pnpm tulipes-mcp --url http://localhost:3000/api/v1/agent --token <bearer token>
```

`--url` is the agent door (`<prefix>/agent`, default
`http://localhost:3000/api/v1/agent`, or `TULIPES_URL`); `--token` is a bearer
token the app's auth module accepts (or `TULIPES_TOKEN`). Without a token the
server calls as guest and lists only what a guest may call.

For Claude Code:

```sh
claude mcp add tulipes-example -e TULIPES_TOKEN="$TOKEN" -- pnpm tulipes-mcp
```

## What it does

- `tools/list` reads the manifest from `GET <url>/tools`, filtered by the
  token's role, and lists each tool with its JSON Schema input and a
  `readOnlyHint` for `GET` routes and actions that say so.
- `tools/call` runs the action **through the app**, at
  `POST <url>/tools/<name>`. The same bearer token goes on every request, so
  the app's auth decides who is calling and its ACL what they may do. This
  package adds no identity of its own and never touches the database.
- A refusal (401, 403, 422) comes back as a tool error carrying the
  envelope's errors, so an agent reads "may not" rather than a crash.

## In code

```ts
import { AgentBridge, createServer } from "@tulipes/mcp";

const bridge = new AgentBridge({ url: "http://localhost:3000/api/v1/agent", token });
const server = await createServer(bridge);
await server.connect(transport); // any @modelcontextprotocol/sdk transport
```

## Generate the manifest without a server

`tulipes agent manifest` writes the same document from an inspection boot —
no service, secret or `.env` — for a tool-definition file or a review of
what an app exposes.
