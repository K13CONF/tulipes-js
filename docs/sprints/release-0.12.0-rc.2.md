# Release — core 0.12.0-rc.2, the 0.12 line's second candidate

Status: **prepared locally, not committed to a tag, not published.** The
release owner decided on 2026-10-13 that the environment change and the
time zones ship in the 0.12 line as its next candidate rather than as a
new line, so rc.1 — committed, never tagged — is superseded by `0.12.0-rc.2`
on npm's `next` tag; `latest` stays on 0.11.0. Owning items: S06 of
[the 0.12b plan](./0.12b-plan.md) and S05/S06 of
[the 0.12 plan](./0.12-plan.md). Tagging and publishing are authorized
operations, not side effects of this commit.

## Scope and acceptance

Everything rc.1 carried (scoped RAI ids, prefix grants, role metadata,
`tulipes migrate 0.12`), plus:

- **One config.** A module's environment values are declared in its
  package.json `tulipes.env` as an object keyed by camelCase config name
  with `key` naming the variable, and read as `ctx.config.<module>.<name>`
  beside its settings: read-only, non-enumerable, never persisted or
  serialised, refused under inspection. `config/app.config.ts` receives
  the values and wires `server.port`, `mongoose.*` and `bullmq.redisUrl`.
  `Environment`, `ctx.Environment`, `KnownVariables` and the
  `@tulipes/core/env` subpath are gone. `tulipes migrate 0.12` carries the
  environment across as well as the ids.
- **Time zones.** `config.timezone`, `req.timezone` / `req.time`,
  `ctx.time`, `process.env.TZ` for the boot, BullMQ cron zones and
  `ctx.queues.schedule()`.
- Packages: core `0.12.0-rc.2`, `@tulipes/cli` `0.3.0-rc.2`, `@tulipes/spec`
  `0.4.0-rc.2` (core `^0.12.0-rc.1`, no source change), `@tulipes/mongoose`
  and `@tulipes/bullmq` `0.2.1-rc.2` and `@tulipes/testing` `0.1.1-rc.2`
  (core `^0.12.0-rc.2`: they read the config keys the app wires),
  `@tulipes/socket.io` `0.1.3-rc.2` and `@tulipes/mcp` `0.1.1-rc.2` (no
  source change; republished because packing rewrites their core
  dependency). Eight archives, dist-tag `next`.
- Migration: `tulipes migrate 0.12` on an app generated by 0.11.0, then
  the 0.12.0-rc.2 sections of `packages/core/MIGRATING.md`.
