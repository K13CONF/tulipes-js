This tutorial builds one application from an empty directory to a deployed
service: a bookstore API with a public catalogue, a back office for editors,
background jobs, live notifications, tests and generated API documents.
Every chapter builds on the previous one, and every command in it was run
against the published 0.13 packages.

## What we will build

```txt
                 ┌────────────────────────────────────────────┐
  guest, user ──►│ GET  /api/v1/books        search, filter,  │
                 │ GET  /api/v1/books/:isbn  sort, paginate   │
                 ├────────────────────────────────────────────┤
  editor,     ──►│ POST   /api/v1/books      add              │
  admin          │ PATCH  /api/v1/books/:isbn change          │
                 │ DELETE /api/v1/books/:isbn withdraw (soft) │
                 └──────┬──────────────────────────┬──────────┘
                        │ queue "books.added"      │ socket /books
                        ▼                          ▼
                 worker process              "book.created"
                 announces the book          to every client
```

By the end you will have:

- a `books` module with a `Book` model stored in MongoDB, snake_case fields,
  timestamps and soft delete;
- a catalogue clients can search, filter, sort, group and paginate through
  the list-query language, without a line of query parsing of your own;
- zod validation on every input, translated errors in English and French,
  and one response envelope for success and failure;
- an `editor` role that manages the catalogue, while guests and users only browse;
- a queue job run by a separate worker process, with retries;
- a Socket.IO namespace that announces each new book;
- a test file that signs in as each role;
- an OpenAPI 3.1 document and a Postman collection;
- PM2 and nginx configuration for staging and production.

## Prerequisites

- Node 24.x and pnpm 10 ([installation](/tulipes-js/start/installation/)).
- Docker, or local MongoDB 8 and Redis 7.
- `curl`, and comfort with TypeScript and Express. You do not need to know
  Mongoose, BullMQ or Socket.IO; the tutorial shows each piece it uses.

If you have not booted a Tulipes app yet, the
[quick start](/tulipes-js/start/quick-start/) takes five minutes and
introduces the envelope and `rai()`.
